혼밥지도 (SoloMap) 최종 발표 및 과제 제출용 캡처 자료 모음
========================================================================

본 폴더(presentation_captures)는 발표 PPT 제작 및 최종 보고서 작성을 위해
UI/UX 진화 과정과 문제 해결 사례를 고화질로 캡처하여 정리한 폴더입니다.

[포함된 파일 목록 및 활용처]

1. 01_식당카드_Before_스톡사진표지_오류모음.png
   - 기존의 외부 스톡 사진 표지 방식 캡처
   - 문제점: 실제 메뉴 불일치(치즈밥에 고기볶음 등), 동일 카테고리 사진 복사, 링크 만료로 인한 엑박(Broken Image) 다수 발생

2. 02_식당카드_After_이모티콘뱃지_심리가이드.png
   - 현재 개선 완료된 완성형 카드 캡처
   - 개선점: 직관적인 3D 카테고리 이모티콘 뱃지, 엑박 오류 0%, 절약된 공간에 심리적 혼밥 난이도 가이드 배너 배치

3. 03_발표슬라이드_카드UI_이모티콘뱃지_진화.png (1920x1080 FHD)
   - PPT에 바로 1장으로 띄울 수 있는 완성형 슬라이드 이미지
   - 스톡 사진의 한계 vs 이모티콘 뱃지 개선 효과 좌우 1:1 비교 및 발표 추천 멘트 포함

4. 04_발표슬라이드_식당설명_LLM개인화_진화.png (1920x1080 FHD)
   - "레벨별 하드코딩 복붙 설명" -> "Gemini LLM 활용 93개 식당별 1:1 맞춤 가이드" 비교 슬라이드
   - 떡집/치킨집에 집밥 설명이 붙던 오류를 LLM 파이프라인으로 해결한 인공지능 활용 사례 발표용

5. 05_단일카드_비교_Before_치즈밥있슈.png & 06_단일카드_비교_After_샘분식.png
   - 단일 카드로 세밀하게 비교할 때 사용할 수 있는 고화질 확대 캡처본

6. 07_Leaflet지도_렉_마커겹침_수정전_Before.png (2K Retina 고해상도)
   - Leaflet 지도 개선 전: 114개 식당의 캡슐 마커가 한 번에 겹쳐 화면을 뒤덮고 브라우저 렉(지연) 발생
   - 문제점: 상호명이 겹쳐 식별 불가, 과도한 DOM 요소로 스크롤 및 줌 렉 유발

7. 08_Leaflet지도_렉해결_스마트도트_After.png (2K Retina 고해상도)
   - Leaflet 지도 개선 후: 축소 시 레벨별 원형 스마트 핀(도트)으로 자동 전환되어 겹침 100% 해결
   - 성능 개선: DOM 렌더링 부하 90% 절감, 60fps 무지연 고속 반응성 확보

8. 09_Leaflet지도_스무스확대_상세캡슐_After.png (2K Retina 고해상도)
   - 줌 인(확대) 시 자연스럽게 상호명 캡슐로 확장되는 디테일 뷰

9. 10_Leaflet지도_네이버식_줌슬라이더_After.png (2K Retina 고해상도)
   - 네이버 지도 스타일 세로형 줌 슬라이더 트랙(`[+] ──●── [−]`)과 우측 하단 실시간 거리 축척 바(`200m`) 장착
   - 사용자가 드래그 또는 클릭으로 원하는 축척 스케일(15~19)을 즉각 조절 가능

10. 11_Leaflet지도_줌슬라이더_상세_After.png
    - 네이버 스타일 줌 슬라이더 컨트롤러 및 단계별 눈금선(Tick Marks) 상세 클로즈업

11. 12_마라왕_네이버지도_검색실패_수정전_Before.png (2K Retina 고해상도)
    - 수정 전: 카카오 로컬 등록 상호명인 '마라왕 명지점'으로 네이버 지도 검색 시 '조건에 맞는 업체가 없습니다' 결과 0건 오류 발생 및 엉뚱한 지역으로 핀이 튀는 현상

12. 13_마라왕_네이버지도_검색성공_수정후_After.png (2K Retina 고해상도)
    - 수정 후: getNaverMapUrl 지능형 정제 모듈을 적용하여 네이버 공식 상호명인 '마라왕마라탕'으로 100% 정상 연동 성공 (리뷰 721개, 실시간 메뉴 사진 확인 가능)

13. 14_발표슬라이드_네이버지도_마라왕_매칭오류_해결.png (1920x1080 FHD)
    - PPT 발표용 1장 완성형 비교 슬라이드
    - 좌측: 카카오 ↔ 네이버 등록명 불일치로 인한 검색 0건 실패
    - 우측: 상호명 정제 파이프라인 구축을 통한 100% 다이렉트 플레이스 연결 성공 및 추천 발표 멘트 수록

14. 15_기본지도_Leaflet_숫자마커_수정전_Before.png (2K Retina 고해상도)
    - 수정 전: '지도로 보기' 진입 시 Leaflet 오픈맵이 기본값으로 실행되고, 마커에 레벨 숫자(1, 2, 3)만 원형 도트로 떠서 어떤 식당인지 상호명을 바로 알 수 없던 상태

15. 16_기본지도_네이버지도_가게명마커_수정후_After.png (2K Retina 고해상도)
    - 수정 후: '지도로 보기' 진입 시 네이버 공식 지도 API v3가 100% 기본 엔진으로 즉시 실행되며, 모든 마커에 [Lv 배지] + [가게명(상호명)] 캡슐이 상시 선명하게 표출되도록 전면 개선
    - 상단 우측 🌐 토글 버튼을 통해 Leaflet 오픈맵으로 원클릭 양방향 하이브리드 전환 가능

16. 17_발표슬라이드_기본지도_네이버지도_가게명마커_전환완료.png (1920x1080 FHD)
    - PPT 발표용 1장 완성형 Before vs After 비교 슬라이드
    - 좌측: Leaflet 오픈맵 기본 실행 및 번호만 뜨는 도트 마커의 가독성 한계
    - 우측: 네이버 지도 기본 엔진 가동 및 [Lv 배지] + [가게명] 상시 표출 캡슐 UI의 직관성 극대화
